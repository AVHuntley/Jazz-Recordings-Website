# Survey of Jazz Recordings

A history of jazz styles and figures, taught through selected recordings — 35 lessons with
curated tracks, timestamped listening guides, and cited sources.

**Live site:** https://avhuntley.github.io/Jazz-Recordings-Website/

**Status: work in progress.** The structure and all 35 lessons are in place; I'm currently
working through the lessons to flesh out the prose.

## Running locally

```
npm install
npm run serve
```

Lesson content lives in `src/lessons/*.md` (one data file per lesson). Writing conventions —
citations, media embeds, listening guides, vocabulary — are documented in
[AUTHORING.md](AUTHORING.md).

## A note on AI

The build tooling for this site was developed with AI assistance. All of the prose and every
lesson-content choice — what to include, what to say about it, which recordings to feature —
are my own. I hold the content to academic citation standards: claims are cited to published
scholarship and primary sources, never to an AI as an arbiter of truth.
